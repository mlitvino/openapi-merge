# openapi-merge workspace

Monorepo workspace for the `openapi-merge` package.

## Structure

- `packages/openapi-merge` — OpenAPI merge library
- `pnpm-workspace.yaml` — workspace package configuration

## Requirements

- Node.js 18+
- pnpm

## Common commands

- `pnpm test` — run package tests
- `pnpm e2e` — run the e2e script
- `pnpm build` — build all workspace packages
- `pnpm typecheck` — run TypeScript checks
- `pnpm lint` — lint the package
- `pnpm format` — format the workspace

## Package docs

See `packages/openapi-merge/README.md` for library usage and package-specific details.
